# Дереккөздер және мәртебе

Қолда бар дереккөз — пайдаланушының мәтіндік техникалық тапсырмасы. «ІТ терминдер ғылыми жоба.docx» берілмеген, сондықтан оның кестелері оқылды немесе тексерілді деп мәлімдемейміз.

Тапсырмадан: алғашқы он ұғым, алты салыстыру жұбы, mouse үшін 62,9 / 21 / 16,2; hard disk үшін 60,8 / 24,9 / 14,3; 483 қатысушы және 2025 жылғы 2–15 желтоқсан. Бірінші қосынды 100,1% күйінде сақталды.

Оқу қосымшалары: қалған 16 ұғым, қысқа анықтамалар, сөйлемдер, орысша және ағылшынша аудармалар, тәсілдердің жалпы түсіндірмелері. Бұлар бастапқы зерттеу авторына телінбейді. Терминдердің ресми мәртебесі көрсетілмейді. Бір нұсқа жалғыз дұрыс деп есептелмейді.

Тексеруді қажет етеді: software атауларының толық тізімі, салыстыру кестесінің бағандары, әр терминнің жіктелуі, терминдердің бастапқы құжаттағы нақты орындары. Тәсілдер қиылысуы мүмкін; әзірге барлығы unknown санатында.

Termincom.kz интеграциясы да, ағымдағы ресми дереккөздерді тексеру де жүргізілген жоқ. Оқушылармен сынақ немесе білім әсерін өлшеу жасалмады.

## Статистика дереккөзін нақтылау

Кейін статистика бастапқы жарияланыммен салыстырылды: Б. Е. Кеңес, Ш. Құрманбайұлы. «Қазақ тіліндегі ақпараттық технология (IT) терминдерінің қолданысы». TILTANYM, 2023, № 1 (89), 169–181. DOI: https://doi.org/10.55491/2411-6076-2023-1-169-181. PDF: https://qazcorpus.kz/_oqu-ishorpus/Dengeilyk/pdf/39-42-PB.pdf.

172-бетте 483 қатысушы және сауалнама мерзімі 2021 жылғы 16–25 наурыз деп берілген. Сайттағы бұрынғы 2025 жылғы желтоқсан мерзімі осы жарияланым бойынша түзетілді. Mouse және Keyboard диаграммалары 173-бетте, Hard disk және Software диаграммалары 174-бетте тексерілді. Keyboard пен Software деректері қосылды. Жолақтардағы сандар бастапқы пайыздардан өзгертілмеді; Mouse қосындысы 100,1% екені ескертілді. Бұл деректер жаңа сауалнама емес, 2023 жылы жарияланған зерттеу нәтижелері.

Software пайыздарының қосындысы да 101% болады (57,5 + 14,7 + 13,1 + 9,3 + 6,4). Бастапқы басылымдағы осы айырма түзетілмей, сайтта белгіленді.
