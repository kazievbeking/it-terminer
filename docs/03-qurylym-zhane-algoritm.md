# Құрылым және алгоритм

`index.html` — төрт бөлім. `css/styles.css` — бейімделетін дизайн. `js/app.js` — жүктеу және зерттеу бөлімі; `i18n.js` — аудармалар; `dictionary.js` — сөздік; `quiz.js` — тест. `data/` — терминдер мен зерттеу сандары, `locales/` — үш тілдегі интерфейс.

Іздеу сұрауын енгізу → Unicode қалыпқа келтіру → кіші әріпке ауыстыру → үш атау мен баламаларды тексеру → тәсіл сүзгісін қолдану → нәтижелерді көрсету.

Тілді таңдау → JSON жүктеу → HTML lang өзгерту → интерфейс пен ашық карточканы жаңарту. Іздеу мен сүзгі сақталады.

Тестті бастау → бес бірегей ұғымды таңдау → төрт нұсқаны көрсету → жауапты белгілеу → түсіндірме → қорытынды. Жауап берілген соң нұсқалар бұғатталады. Қайталау жаңа сұрақтар таңдайды. Нәтиже localStorage ішінде сақталады; сақтау бұғатталса да сайт жұмыс істейді.
