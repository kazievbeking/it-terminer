# Тексеру нәтижелері

Автоматты тексеру Node VM және DOM үлгісі арқылы жүргізілді:

- 26 термин және үш JSON аудармасының кілттері тексерілді.
- Төрт JavaScript модулінің синтаксисі тексерілді.
- Қазақша, орысша, ағылшынша және «тышқан» нұсқасы бойынша іздеу өтті.
- Бос сұрау нәтижесі мен бос тәсіл сүзгісінің хабарламасы тексерілді.
- Модаль ашу және жабу өңдегіштері орындалды.
- Бес сұрақтық тест, әр жауаптан кейінгі түсіндірме, нәтижені сақтау және қайта бастау өтті.
- Тесттің ортасында тілді ауыстыру сұрақ пен жауапты сақтады.
- Диаграмма сандары тапсырмамен салыстырылды; алты жұп бар.

Шектеу: бұл толық браузерлік сынақ емес. Мобильді экран, нақты фокус шектеуі, Escape, визуалды контраст және браузер консолі қолмен тексеруді қажет етеді. GitHub-та жариялау орындалмады. Бастапқы DOCX-пен салыстыру мүмкін болмады. Оқушылармен тест жүргізілген жоқ.

Болашақ скриншот: тесттің соңғы экраны — нәтиже мен қайта өту батырмасы.

Қосымша: уақытша жергілікті HTTP сервері арқылы 11 ресурс (HTML, CSS, төрт JS, екі дерек JSON және үш аударма) сәтті жүктелді. Сервер тексеруден кейін жабылды.

Карточкаларды жаңарту: JavaScript синтаксисі, 26 карточка, үш тіл панельдері, дереккөзді ашу, ашық карточка тілін жаңарту және жабу DOM үлгісімен тексерілді. Қосылған браузер жоқ болғандықтан визуалды тексеру орындалмады.

## 10 тапсырмалық тестті тексеру

200 кездейсоқ әрекетте тапсырма саны мен құрамы тексерілді: 5 аударма, 2 сәйкестендіру, 2 тәсіл, 1 анықтама. Әр таңдаулы тапсырмада жалғыз дұрыс нұсқа бар. Сәйкестендіруде үш бірегей жұп бар. Толық әрекет 10/10 нәтижемен орындалды; кері байланыс, нәтиже сақтау, қайта бастау және тіл ауысқанда сәйкестендіру мәндерін сақтау DOM үлгісімен тексерілді. Дереккөз сілтемелері мен статистиканың дереккөз блогы интерфейстен алынды.
