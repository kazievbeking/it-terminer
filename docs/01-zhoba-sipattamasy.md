# IT терминдер

Мақсаты — қазақша IT атауларын үш тілде салыстыруға көмектесу. Нысаналы аудитория — оқушылар мен ғылыми жоба тыңдаушылары. Мәселе: бір ұғымның бірнеше атауы қатар қолданылады.

Бастапқы ғылыми DOCX берілмеген. Қазір техникалық тапсырмадағы мысалдар ғана негізге алынады. Қосымша сөздер мен анықтамалар — оқу материалы, зерттеу қорытындысы емес. Құжат келгенде деректер мен жіктеулер қайта қаралады.
