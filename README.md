# IT терминдер

Үш тілдегі шағын оқу сайты: 26 ұғым, іздеу, сүзгі, қолжетімді модаль терезе, бес сұрақтық тест және екі диаграмма. HTML, CSS және JavaScript; серверлік код пен құрастыру қажет емес.

## GitHub Pages

1. GitHub-та репозиторий жасаңыз.
2. **Осы `it-terminer` бумасының ішіндегісін** репозиторийдің түбіріне салыңыз: `index.html`, `css`, `js`, `data`, `locales`, `docs`, `.github` және `.nojekyll`. Бастапқы PHP жобасын жүктемеңіз. Жасырын `.github/workflows/pages.yml` файлын да қосыңыз.
3. Репозиторийде **Settings → Pages → Build and deployment → Source → GitHub Actions** таңдаңыз.
4. `main` немесе `master` тармағына өзгеріс жіберіңіз. Қажет болса **Actions → Publish GitHub Pages → Run workflow** басыңыз.
5. Жарияланған мекенжай **Actions** нәтижесінде және **Settings → Pages** ішінде көрсетіледі: `https://USERNAME.github.io/REPOSITORY/`.

Барлық ресурс жолдары салыстырмалы, сондықтан репозиторий атауы еркін. Сайтты GitHub-қа жүктеу мен аккаунттағы Pages параметрін таңдау пайдаланушы тарапынан орындалады.

## Жергілікті іске қосу

Python 3 орнатылған болса, осы бумада:

```sh
python -m http.server 8000
```

Браузер: `http://localhost:8000/`. OSPanel арқылы: `http://oyu/it-terminer/` (домен HTTP серверіне бағытталған болса). `index.html` файлын `file://` арқылы ашпаңыз: JSON HTTP арқылы жүктеледі.

## Деректер мен шектеулер

Бастапқы «ІТ терминдер ғылыми жоба.docx» берілмеген. Он термин мен алты жұп тапсырмадан алынды; қалған 16 термин — ашық белгіленген оқу қосымшасы. Барлық жіктеу әзірге «Нақтылауды қажет етеді»; сондықтан расталмаған жіктеу сұрақтары тестке енгізілмеді. Бос тәсіл сүзгілері тиісті хабарлама көрсетеді. Бағандарды Termincom.kz не оқулықтарға телу DOCX тексерілгенше жасалмайды.

Диаграммалар тапсырмадағы сандарды дәл сақтайды, бірақ түпнұсқамен салыстыру жасалмаған. Google Fonts қолжетімсіз болса, жүйелік қаріп қолданылады. Деректер сыртқы қызметке жіберілмейді. Тіл, іздеу және соңғы тест нәтижесі браузерде сақталады.

Қазақша құжаттама: `docs/`. Деректерді қайта жасауға арналған қосымша сценарий: `generate-data.ps1` (күнделікті жұмысқа қажет емес).
